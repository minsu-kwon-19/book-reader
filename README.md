# 책틈 · Book Reader

## 서버 동기화

Vercel 배포는 Upstash Redis 무료 저장소와 `/api/sync` 함수를 사용합니다. `KV_REST_API_URL`, `KV_REST_API_TOKEN`, `BOOK_READER_SYNC_KEY`, `BOOK_READER_USERNAME`, `BOOK_READER_PASSWORD_HASH`를 Vercel 프로젝트의 Production 환경 변수로 설정합니다. 비밀번호는 scrypt 해시로 서버에서 확인하며 로그인 세션은 HttpOnly 쿠키로 유지합니다.

로그인하면 서버 기록을 자동으로 불러옵니다. 기록 변경은 즉시 서버에 전송하며, 열린 화면은 15초마다 최신 기록을 확인합니다. 기존 브라우저 `localStorage` 기록은 사이트를 열 때 삭제합니다. 독서 기록은 브라우저에 영구 저장하지 않습니다.

독서 계획을 달력에 펼쳐 놓고 읽은 날을 체크하는 개인 독서 서비스입니다.

## 기능
- 월별 달력, 날짜별 독서 계획 및 읽기 체크
- 읽는 중 / 읽을 책 / 다 읽은 책 분류와 제목·저자 검색
- 책 등록·수정·삭제, 독서 기간, 페이지 진행률
- 서버 자동 저장, JSON 백업·복원, 반응형 화면

책 제목이나 표지를 누르면 진행률과 상태를 수정할 수 있습니다. 읽기 체크는 날짜만 기록하며 페이지를 자동으로 늘리지 않습니다.

## 실행과 검증
Node.js 22 이상. 외부 npm 의존성이 없습니다.

```sh
npm run dev
npm test
npm run build
```

미리보기: http://127.0.0.1:5173
PowerShell 실행 정책으로 차단되면 npm.cmd를 사용합니다.

## Vercel 배포
```sh
vercel login
vercel --prod
```

vercel.json에 빌드와 출력 경로가 설정되어 있습니다. Git 저장소를 가져올 때는 Framework Preset: Other, Build Command: npm run build, Output Directory: dist를 사용합니다. 환경 변수는 필요하지 않습니다.

## 데이터
로그인 후 두 사람의 기록은 서버에 저장됩니다. 복원은 확인 후 선택한 책장 전체를 교체합니다. 서버 저장에 실패하면 화면에 동기화 오류를 표시합니다.

Google Fonts가 연결되지 않으면 시스템 글꼴을 사용합니다.

## 본깨적
책장의 본깨적 버튼이나 책 제목을 눌러 본 것·깨달은 것·적용할 것을 적고 저장할 수 있습니다. 각 항목은 선택 사항이며 5,000자까지 지원합니다. JSON 백업·복원에도 포함되며, 이전 백업도 호환됩니다.

## 100권 독서 계획
사용자가 지정한 100권은 새 서버 기록을 만들 때 추가됩니다. 기존 제목이 있으면 중복 추가하지 않고 기존 본깨적·일정·읽기 기록을 유지합니다. 삭제한 기본 책은 새로고침 시 다시 생기지 않습니다. 달력 날짜를 누르면 제목 검색이 가능한 책 선택창이 열립니다. 이미 일정이 있거나 완독한 책은 제외되며, 일정에서 빼면 다시 배정할 수 있습니다. 완독과 날짜별 읽기 체크는 별개입니다. 페이지 수와 저자는 임의로 채우지 않으며, 필요할 때 수정할 수 있습니다.

## 드래그 이동과 두 사람 프로필
달력에 배정된 책을 다른 날짜로 끌어 옮길 수 있습니다. 기간이 있는 계획은 기간 전체가 같은 일수만큼 이동하며, 실제 읽은 날짜와 본깨적은 유지됩니다. 터치 드래그도 지원하며, 책 수정 창에서 날짜를 직접 입력하는 방식도 사용할 수 있습니다. 달력 제목은 데스크톱 13px, 모바일 12px로 표시합니다.

상단의 기록하는 사람 메뉴로 두 프로필을 전환하고 이름 설정에서 이름을 바꿀 수 있습니다. 기존 기록은 첫 번째 프로필에 그대로 남고, 두 번째 프로필에는 기본 100권이 별도로 추가됩니다. 일정·완독·본깨적과 백업·복원은 선택한 사람에게만 적용됩니다. 두 프로필은 하나의 로그인 계정 아래에서 사용하며 기기 간 동기화됩니다.

## 함께 보는 달력
두 사람의 책과 읽은 날은 달력에 함께 표시되고 각 이름과 색으로 구별됩니다. 책장과 본깨적은 선택한 사람별로 유지됩니다. 일정 이동·읽기 체크·완독은 현재 선택한 사람의 책에만 적용할 수 있습니다. 다른 사람의 기록을 수정하려면 상단에서 그 사람을 선택하세요. 열린 화면은 서버 변경 사항을 주기적으로 확인합니다.

## 날짜별 본깨적
달력 날짜를 누르면 오른쪽에 두 사람의 책이 이름과 함께 보입니다. 책 제목을 누르면 본 것·깨달은 것·적용할 것만 적는 창이 열립니다. 선택한 사람의 기록만 편집할 수 있고 다른 사람의 기록은 읽기 전용입니다. 날짜에 책을 추가하려면 오른쪽의 ‘이날 독서 계획하기’를 누르세요. 웹 화면에서는 책 삭제 버튼을 제공하지 않습니다.

## 독서 기간 빠르게 조절하기
달력 날짜를 누른 뒤 오른쪽 책 목록에서 해당 책의 +1일 또는 −1일을 누르면 완독 목표일을 하루씩 조절합니다. 하루짜리 계획은 더 줄일 수 없습니다. 기간을 늘리면 달력의 추가 날짜에도 책이 표시되고, 읽은 날 기록과 본깨적은 유지됩니다. 일정이 월말이나 연말을 넘어가도 날짜가 이어집니다.
